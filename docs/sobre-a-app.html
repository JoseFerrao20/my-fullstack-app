Aplicação full-stack

Task Manager

Uma aplicação web para organizar tarefas pessoais: cada utilizador cria a sua conta, regista tarefas com prioridade, categoria e prazo, e recebe avisos quando um prazo se aproxima ou já passou.

Contas de utilizador

Registo, login e logout. A sessão é renovada automaticamente e cada pessoa só vê os seus próprios dados.

Gestão de tarefas

Criar, editar, concluir e apagar tarefas, com estado (por fazer, em curso, concluída), prioridade e prazo.

Categorias e prioridades

Categorias com cor definidas pelo utilizador e quatro níveis de prioridade: baixa, média, alta e urgente.

Pesquisa e filtros

Filtrar por estado, prioridade e categoria, pesquisar por texto, ordenar e paginar. Os filtros ficam no URL.

Notificações de prazos

A cada minuto o servidor gera alertas de "a terminar" (próximas 24 h) e "em atraso", mostrados num sino com contador.

API documentada

API REST com documentação OpenAPI interativa em /docs, com o mesmo formato de resposta em todos os pedidos.

Tecnologias

  • Frontend: React 18, TypeScript, Vite, Tailwind CSS
  • Backend: Python 3.12, FastAPI, SQLAlchemy
  • Base de dados: PostgreSQL
  • Testes: Vitest e Pytest
  • Execução: Docker e docker-compose

Como executar

  • Na raiz do projeto: docker compose up --build
  • Aplicação: http://localhost
  • Documentação da API: http://localhost:8000/docs
  • Detalhes de desenvolvimento em CLAUDE.md
